Hola! Soy Adrián Xavier Brioso Jurado y este es mi 2do proyecto de programación del Primer año de Ciencias de la Computación.

Este proyecto sigue las directrices que se nos indicaron pero presenta los siguientes cambios:
1) El comando Spawn puede ser usado más de una vez ya que esto facilita mucho el dibujado (no se spawnean varios WallEs, se mueve el WallE ya creado). Además, no es necesario que sea lo primero que se introduzca en el input.
2) El comando DrawLine ubica a WallE en el ultimo pixel que se pinta. En el .pdf se indicaba que WallE se ubique un pixel más allá en la misma direccion que se introduzca pero esto hace más confuso y difícil dibujar.
3) Mi proyecto admite variables con valor de tipo string.
4) Más colores de los requeridos.
5) El GridLayoutGroup donde estan los pixeles esta limitado a 256x256 y es siempre cuadrado.

Además recomiendo no introducir tamaños de GridLayoutGroup superiores a 100x100 ya que se merma mucho el rendimiento del proyecto(100x100 genera 10000 objetos en escena).
Las escenas tienen botones y objetos con texto para facilitar el uso del intérprete.
